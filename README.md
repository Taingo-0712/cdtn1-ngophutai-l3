# L3 – Cơ hội bán hàng và phễu bán

**Sinh viên:** Ngô Phú Tài – MSSV: 2374802010441 – Track SE  
**Học phần:** Chuyên đề Tốt nghiệp 1, HK1 2026–2027  
**Case study:** Smart CRM – Mekong Mobile

## 1. Mục tiêu

Xây dựng một ứng dụng web giúp nhân viên bán hàng ghi nhận và theo dõi cơ hội từ khách hàng quan tâm. Cơ hội được chuyển qua các giai đoạn Tiếp cận, Tư vấn, Báo giá và Chốt. Quản lý cửa hàng có thể xem số cơ hội ở từng giai đoạn của phễu bán.

Phạm vi này đang chờ giảng viên phê duyệt; dự báo doanh thu chưa nằm trong chức năng cốt lõi.

## 2. Yêu cầu môi trường

- Node.js và npm
- PostgreSQL cục bộ
- Git và Visual Studio Code
- Các biến cấu hình dự kiến: xem `.env.example`

Công nghệ dự kiến: JavaScript, Express.js và Bootstrap. Phiên bản phần mềm sẽ được ghi sau khi kiểm tra trên máy chạy dự án.

## 3. Hướng dẫn chạy

Sẽ cập nhật sau khi đưa ứng dụng và cơ sở dữ liệu vào repo. Hiện chưa có lệnh chạy hoàn chỉnh.


## 4. Cấu trúc thư mục

- `docs/`: tài liệu, khai báo sử dụng AI và ảnh minh chứng.
- `src/`: mã nguồn ứng dụng.
- `tests/`: mã kiểm thử.
- `data/`: dữ liệu mẫu nhỏ hoặc hướng dẫn sinh dữ liệu mô phỏng.

## 5. Kiểm thử

Sẽ cập nhật lệnh chạy và kết quả kiểm thử khi có test.
npm test → hiển thị số test PASS
